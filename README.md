# 训练异常诊断能力 · 交互原型

大模型训练平台的训练异常诊断功能原型，演示一次 Loss 突变异常从告警到结论确认的完整链路。

**在线预览**：https://<你的用户名>.github.io/train-diag-prototype/

## 五步流程

| 步骤 | 环节 | 主导方 |
|---|---|---|
| 1 | 告警发现 | 系统触发 |
| 2 | 集群判别 | 系统定域 |
| 3 | 诊断结论 | 系统归因 |
| 4 | 证据与对比 | 系统取证 |
| 5 | 确认与回流 | 工程师拍板 |

## 核心设计

- **归属域前置判别**：先区分任务内部问题与集群级事件，再进入归因
- **差异归因**：在配置、数据配比、训练阶段三个维度检索相似实验并计算差异
- **条件性异常识别**：配置无差异时，通过条件对照表定位触发条件
- **证据准入**：无可溯源证据的候选原因不予展示，宁可少给一条
- **规则与大模型分工**：规则负责判定与排序，大模型只负责表述与归纳
- **三出口设计**：采纳 / 搁置 / 否决，搁置需填原因用于定位缺陷环节
